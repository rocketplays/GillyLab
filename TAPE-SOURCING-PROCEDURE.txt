TAPE SOURCING — THE PROCEDURE
=============================
How to find free YouTube links for a fighter's PRE-UFC bouts. Follow this
exactly, ONE FIGHTER AT A TIME. Working in bulk across fighters loses bouts,
because the moment one query hits you stop looking. Do not do that.

Companion files:
  TAPE-REVIEW-QUEUE.txt   — the long history, every trap, why each rule exists.
  scripts/place-tape-links.cjs   — places links (see FORMAT below).
  scripts/fix-tape-sections.cjs  — repairs Pre-UFC / UFC section headers.
  scripts/check-tape-links.py    — sweeps all YouTube links for dead ones.


PER-FIGHTER LOOP  (finish a fighter completely before the next one)
------------------------------------------------------------------
0. LIST THE GAPS. Get the fighter's unlinked pre-UFC bouts and the promotion +
   event + date of each (see "GET THE GAP LIST" below).

1. PROMOTION SWEEP. For each promotion in that list, find its YouTube channel
   and see what it has. NOTE: a channel's /videos tab is NOT a full inventory
   (@GlobalKnockout shows 3 videos but hosts 4+ bouts). Search the channel, do
   not just browse it. Channel-scoped search (/@handle/search?query=) is also
   truncated/unreliable — treat it as a hint, not proof of absence.

2. EVERY REMAINING BOUT, BARE "<Fighter> vs <Opponent>", one at a time, no
   qualifiers. Do NOT stop when one hits. Do not lead with the promotion, the
   year, or the words "full fight" — those SUPPRESS the regional result and
   surface the fighter's UFC career instead.

3. FOR ANY STILL MISSING, retry with the EVENT NUMBER instead of the opponent:
   "GKO 4 Anthony Hernandez", "WWFC 10 Spivak", "LFA 108 Rodrigues".
   THIS STEP IS MANDATORY. It finds two things a name-pair query never can:
     a. uploads titled with only ONE fighter ("Anthony FLUFFY Hernandez @ GKO 3")
     b. uploads the plain search buried under the UFC-era noise (LFA 108).

4. NATIVE-LANGUAGE / ALT-SPELLING PASS for anyone non-Anglophone. Look up the
   fighter's name in their own script and search THAT, and translate the
   promotion too:
     Chinese   Aoriqileng 傲日其楞 · Song Yadong 宋亚东 · Sumudaerji 苏木达尔基
     Japanese  Kai Asakura 朝倉海 · Rei Tsuruya 鶴屋怜 · Kyoji Horiguchi 堀口恭司
     Korean    Seokhyeon Ko 고석현
     Russian   Ислам Махачев · Мыктыбек Оролбай · use for ProFC/M-1/ACA/WWFC
     Portuguese "luta completa", the fighter's Portuguese nickname
     PROMOTION TRANSLATION MATTERS: WLF's MMA arm is 武林笼中对, NOT the
     kickboxing show 武林风. Searching the wrong one returns nothing.

5. VERIFY EVERY ID BEFORE PLACING. No exceptions. Run oembed:
     curl -s "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<ID>&format=json"
   JSON back = playable, and it gives you the real title + channel.
   ANY failure (Forbidden / 404 / 401 / 403) = DEAD or private = DO NOT PLACE.
   (Proven twice: every oembed failure this project was an unplayable video.
   "Forbidden" is NOT "embedding disabled but fine" — that assumption put 4
   dead links live.)

6. PLACE (see FORMAT), then run fix-tape-sections.cjs --write.

7. Only now move to the next fighter.


TRAPS THAT HAVE CAUSED WRONG LINKS
----------------------------------
- REMATCHES. Many fighters met an opponent twice (once regional, once UFC).
  The placer REFUSES an unpinned rematch — add a year pin: "@2018". Examples
  hit: Hernandez vs Brendan Allen (LFA 2018 + UFC), Petrino vs Bellato
  (Max Fight 2019 + DWCS 2022 — the DWCS video is NOT the pre-UFC bout),
  Karine Silva vs Dione Barbosa, Makhachev vs Storley.
- NAME-COLLISION SUBSTITUTION. The search engine swaps in a famous name:
  "Neil Magny vs Nate Pratt" -> Carlos PRATES; "Barboza vs Lee King" -> Kevin
  LEE. CONFIRM the returned title contains the opponent you asked for.
- WRONG NAMES IN OUR OWN DATA. Match on EVENT + DATE, not spelling, and flag
  the row for a FIGHT_HISTORY fix. Confirmed wrong: "Markus Prödl" is actually
  Marcus Plodeck; "Simone da Silva" (Karine Silva, SFT 21) is Simone Duarte;
  "Christina Adcock" (Jasudavicius, BTC 8) is Christina Ricker.
- SECONDARY CHANNELS ARE FINE (the standard is real footage, not simulation).
  A pre-UFC regional bout CANNOT be an EA-game sim — the games only ship UFC
  rosters. Reject only "UFC 4/5 AI Simulation", "Gameplay", "CPU vs CPU", and
  titles that name only one fighter with no event. Judge the TITLE, not the
  channel. Cageside GoPro on a personal channel counts.

PLACE  (FORMAT)
---------------
Write a temp file, one line per bout (add " @YYYY" before "(" for rematches):
  - Vitor Petrino vs Rodolfo Bellato @2019 (https://www.youtube.com/watch?v=<ID>)
Then:
  node scripts/place-tape-links.cjs /tmp/that-file.txt --write
  node scripts/fix-tape-sections.cjs --write
The placer REPLACES a fighter's whole block, so a temp file with only new bouts
is fine — it merges with existing rows by video id. It will REFUSE to write if
any row doesn't resolve or a rematch lacks a pin. Trust its refusal.

Do NOT run mutating git from the sandbox (leaves a .git/index.lock). Commit in
Terminal. If a sandbox read fails with errno -35 / "Resource deadlock avoided",
that is iCloud offload, NOT damage — the file is fine on the Mac; `cat` it there
once to rehydrate, or just retry.
